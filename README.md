# Freight Train Polymorphism Simulator

## Project Description
This Java project models a freight train using **polymorphism, inheritance, abstract classes, and interfaces**.  
Users create engines and train cars through interactive **factory methods**, then the program calculates total train weight, applies brakes to every car, and computes the time required to reach **100 km/h** based on engine power and train mass.

The system demonstrates real-world object-oriented design, including abstract behavior, shared interfaces for braking, and dynamic car creation using ArrayList.

## Technologies Used
- **Java 17+**
- **OOP Principles**
  - Polymorphism  
  - Inheritance  
  - Abstract Classes  
  - Interfaces
- **Factory Design Pattern** (static `create()` methods)
- **ArrayList** for dynamic train structure
- **Console-based input/output**
